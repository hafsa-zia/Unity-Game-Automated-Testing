Unity Game Testing Project
This repository contains a Unity-based game with a suite of automated tests to validate core game functionalities. The tests are written using the NUnit framework and executed through Unity's Test Runner. The goal is to ensure the stability and functionality of various game systems, including player movement, enemy AI, scoring, health, stamina, and more.

Features
Player Movement: Tests to validate correct movement in response to user input.
Enemy AI: Ensures enemies can detect and chase the player within a specified range.
Score System: Validates the score incrementation when collecting items.
Health and Stamina Systems: Tests to ensure health and stamina management work correctly.
Obstacle and Collectible Systems: Verifies that obstacles and collectibles are handled properly during gameplay.
